# Expense Tracker

A full-stack Expense Tracker web application built using the MERN stack.

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript
- Axios

### Backend
- Node.js
- Express.js
- Mongoose
- JWT
- bcryptjs

### Database
- MongoDB Community Server
- MongoDB Compass
